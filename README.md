# Skills

### <ins>Embedded Linux</ins>

**My primary skill is embedded Linux development, especially for Xilinx FPGAs ([PetaLinux](https://www.amd.com/en/products/software/adaptive-socs-and-fpgas/embedded-software/petalinux-sdk.html)).** For years, I've worked as a FPGA engineer to design custom hardware interfaces in HDL (`VHDL` or `Verilog`) and customized embedded Linux images in PetaLinux for ZYNQ Ultrascale [MPSoC](https://www.amd.com/en/products/adaptive-socs-and-fpgas/soc/zynq-ultrascale-plus-mpsoc.html) and [RFSoC](https://www.amd.com/en/products/adaptive-socs-and-fpgas/soc/zynq-ultrascale-plus-rfsoc.html).<br>

I also have built embedded Linux images for [Raspberry Pis](https://medium.com/nerd-for-tech/build-your-own-linux-image-for-the-raspberry-pi-f61adb799652) and [Beaglebone Black](https://www.beagleboard.org/projects/yocto-on-beaglebone-black) SBCs (Single Board Computers).


### <ins>FPGA Design</ins>

Second to my skill in embedded Linux is FPGA development. While I have worked on Altera FPGAs before, I primarily work on Xilinx FPGAs (Kintex and Zynq) using Vivado. While I have used VHDL (primarily in academia) and I am learning `Scala`-based HDLs, I'm mostly experienced in `Verilog`.<br>

The design tools I've mainly used is `Vivado`, but I have also used `ModelSim` and `Quartus Prime` before.
